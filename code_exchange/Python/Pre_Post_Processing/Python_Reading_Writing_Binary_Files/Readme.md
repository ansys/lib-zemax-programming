# Python Reading Writing Binary Files (ZRD, ZBF, DAT, SDF)

## Overview

The download contains 3 Python scripts:

1. A script to read / parse a ZRD (Zemax Ray Database) file.
2. A script to read / parse a Binary ZBF (Zemax Beam File) file.
3. A script to read / parse a Binary DAT / SDF Source File
