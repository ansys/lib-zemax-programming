# Generating ZBF from Excel

## Overview

This Python code converts Excel data into ZBF text format. A sample Excel file is provided as *ZBF_Example.xlsx*.

## Author
Yuan Chen

## Instructions

#### 1. Installation
Once Python is installed, install the necessary libraries: pandas, openpyxl, tkinter.

The Python script is ready to be used as part of file pre-/post-processing. 

#### 2. How to use
1. Use the sample Excel file: *ZBF_Example.xlsx* to store the data that you want to convert.
2.	Execute the script, select the folder where you placed the Excel file, and wait for the generation of the ZBF file. The generated ZBF file has the same name and is placed in the same folder as the Excel file.
3.	After generation, please make sure to copy the ZBF file to your *\Documents\Zemax\POP\BEAMFILES* folder. Alternatively, you can change line 16 to your current BEAMFILES folder.
